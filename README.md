# pdfium-editor — web

A PDF text editor that edits the REAL text layer in your browser: rendering
and editing both run in a WebAssembly build of PDFium + the same C++ editing
core that drives the Android app (verified byte-for-byte identical behavior).

Everything runs locally in the browser — documents never leave your machine.

Open the app, pick a PDF, tap a paragraph, type. Tap outside to commit;
Save streams the result to disk.

Built artifacts only; generated by scripts/build_site.sh in the source repo.
